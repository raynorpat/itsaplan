## [0.5.0](https://github.com/raynorpat/itsaplan/compare/v0.4.0...v0.5.0) (2026-11-26)


### ⚠ BREAKING CHANGES

* remove the REST API
* remove the web features Linear does not have
* remove god mode; passwordless sign-in and workspace settings in the web app
* Organization settings, with secrets and limits from the environment
* **auth:** sign in with magic links, Google or passkeys instead of passwords
* workspace invites, team joining, role changes and suspension
* **api:** replace team roles with Linear's workspace roles and team visibility
* remove the built-in AI agents
* remove team actions, issue types and custom fields
* remove the Telegram bot and team email settings
* remove dashboards, note boards, analytics, share links, webhook test and team copy
* **worker:** remove anonymous telemetry
* **web:** use teams, projects and states
* rename projects to teams and initiatives to projects in the api
* **db:** rename to teams, workflow states and projects; add project tables
* **web:** use uuid ids and integer priority
* switch api, worker and bot to uuid ids and integer priority
* **db:** use uuid ids and Linear issue fields in a new baseline schema
